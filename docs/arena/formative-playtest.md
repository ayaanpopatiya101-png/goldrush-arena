# Formative player test

## Status

Prepared on 2026-11-07. **Zero human participants tested in this task.** Browser automation is engineering verification, not a substitute for uncoached observation. The suggested one-minute first-play goal is unvalidated.

## Recruitment and handling

Recruit 3–5 first-time players who have not been coached on GoldRush. Use participant labels A–E, not names or contact information. Obtain permission before recording. Do not collect unnecessary personal data. Include at least one smaller/older supported physical phone.

Record candidate commit, signed build number, device/OS, input method, accessibility settings and whether the player has prior paddle-game experience. Use fresh **test** local profiles; preserve existing saves. No live-money purchases.

## Moderator script

Say: “Try the game as if you had just installed it. Please say what you expect to happen. I will not explain controls unless you are stuck.”

| Task, in this order | Observe without coaching | Proposed criterion |
| --- | --- | --- |
| Start from entry | Time to meaningful paddle movement; validation hesitation; tutorial Skip use | Most start meaningful play within about one minute |
| Identify your paddle | Ask which edge they protect and which seats are bots | Correct bottom paddle and local-bot understanding without color alone |
| Finish a match | Mis-taps, misses, ball readability, understanding elimination | Can explain why they won/lost |
| Play again | Action found; accidental exit; repeated countdown | Rematch found without help |
| Find next useful unlock | XP rank versus competitive level versus pass points | Can explain at least the next achievable goal and source of progress |
| Compare/equip an owned cosmetic | Compare selected/current, actual equipped state | No mistaken spending or false ownership expectation |
| Find Settings and support | Sensitivity practice, reduced effects, truthful support status | Can locate both; understands local-save limits |

Do not treat a compliment about appearance as task success. Record unread instructions, wrong expectations and hesitation at the time they happen.

## Results sheet

For each participant record:

- Anonymous label / device / candidate.
- Task start and end time; success without help / success with help / unable.
- Exact hesitation, mis-tap or quoted expectation (only with consent).
- Whether they mistook bots for synchronized humans.
- Whether rewards, unavailable items or profile persistence were misunderstood.
- Severity, likely cause and the smallest testable change.
